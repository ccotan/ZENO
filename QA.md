# Локальная проверка сборки

Проверено на тестовом проекте demo-zeno в Firebase Auth Emulator и Firestore Emulator. Настоящие аккаунты, секреты и рабочая база для тестов не использовались. Discord popup в браузерном тесте имитируется; Firebase Auth и Firestore работают через настоящие SDK 11.10.0 с эмуляторами.

- 50 групп правил Firestore: свой/чужой/анонимный доступ; атомарная регистрация профиля; запрет перехвата и переназначения publicId; закрытость private mapping; проверка схем; серверное время; запрет неверных цен/количеств/товаров/лишних полей; 50 разрешённых слотов и запрет 51-го; запрет изменения остатка; удаление только владельцем; закрытые чаты/сделки. Дополнительно успешно опубликованы и удалены все 1252 itemKey справочника для проверки allowlist и лимита вычисления выражений правил.
- 29 браузерных проверок: два изолированных браузера, вход, сохранение профиля, публикация, публичный просмотр, профиль продавца, разделение владения, перезагрузка, удаление, повторное использование слота и защита от устаревшего удаления, отсутствие смешивания с localStorage, демо-чат/избранное, выход, RU/EN и ширины 320/390/768/1440 для аккаунта. Ноль необработанных JS-ошибок.
- 10 проверок границ: первая порция 100, следующая 1, сброс курсора, поиск по догруженным данным, просмотр лота со следующей страницы, явное состояние permission-denied без ложного успешного пустого каталога. Ошибка доступа для этого сценария инъецирована, а не вызвана изменением рабочих правил.
- 20 регрессионных тестов существующего Worker входа; его код этой сборкой не изменялся.
- Вручную просмотрены снимки общих лотов, аккаунта, публичного продавца, состояния ошибки; мобильный и настольный вид. Базовое оформление V17 не заменялось.

Не проверено в этой сборке: публикация в рабочий Firebase/GitHub Pages, реальный вход Discord после выкладки пользователем, рабочая конфигурация App Check/квот и реальные Minecraft-сделки. Это завершается проверкой после ручной установки по README.
