# ZENO — общие профили и объявления, этап 1

Оформление V17 сохранено. Это новая клиентская сборка и правила Firestore.
Cloudflare Worker Discord v4 менять не нужно. В рабочий Firebase из тестов данные не записывались.

## Что включено

- Вход Discord -> существующий Firebase Auth.
- Публичный профиль: имя на сайте и непроверенный ник Minecraft.
- Общие объявления в Firestore: предмет, количество, цена, своё название, чары как описание продавца.
- Профиль продавца с его объявлениями. Чтение без входа, публикация после входа и заполнения профиля.
- Удаление только владельцем. Максимум 50 активных объявлений на аккаунт проверяется правилами через фиксированные слоты.
- Существующий лот нельзя перезаписать: пока для изменения цены/количества его нужно удалить и опубликовать заново.
- Поиск, категории и сортировка работают по загруженным объявлениям. Сначала читаются последние 100; кнопка «Загрузить ещё» добавляет следующую порцию. Обновление вручную.
- Демо-примеры включаются отдельно и помечены «Демо». Настоящие объявления помечены «Общий лот».

## Пока НЕ подключено

Общий чат, серверные сделки, резервирование, рейтинги, отзывы, история продаж, синхронизация избранного, общие рекламные баннеры и фотографии.
Чат на примерах, черновики, избранное, уведомления демо и реклама остаются в браузере; они не привязаны к Firebase-аккаунту и не исчезают при выходе.
Старые локальные лоты не публикуются автоматически. Общие лоты не участвуют в демо-покупке и не теряют остаток от локальных действий.
Фотографии отключены, Cloud Storage не используется. У предметов остаются штатные текстуры. Закрытые Storage Rules менять на открытые НЕ нужно.

## Важно перед запуском: ранее раскрытый ключ

Если это ещё не сделано, отзови ранее отправленный в чат приватный ключ сервисного аккаунта в Google Cloud IAM -> Service Accounts -> нужный аккаунт -> Keys -> удалить раскрытый ключ.
Создай новый ключ и замени полное содержимое секрета FIREBASE_SERVICE_ACCOUNT в Cloudflare Worker. Новый JSON нельзя класть в GitHub, код сайта или чат. Проверка /health должна снова показать configured:true; затем проверь вход.
Ключ подписи Firebase позволяет создавать токены пользователей: пока раскрытый ключ действителен, проверки владельца не защищают от его использования для подмены аккаунта.
Сам публичный Firebase web config в js/config.js не является этим приватным ключом.

## Установка — по порядку

1. Сохрани резервную копию текущего репозитория/коммита.
2. Открой Firebase Console -> проект zeno-33e37 -> Build -> Firestore Database.
   Если базы нет, создай базу (default) в production mode. Платные Functions и переход на Blaze для этой сборки не нужны.
3. На вкладке Rules замени текущие правила ПОЛНЫМ содержимым файла firestore.rules из этого архива. Нажми Publish. Не вставляй правила Firestore в Cloudflare Worker или js/config.js.
4. Распакуй архив сайта. В GitHub ccotan/ZENO -> ветка main загрузи содержимое распакованного архива в корень с заменой файлов. index.html должен лежать в корне, рядом с папками js, css, assets, data, locales, а не внутри дополнительной папки public.
5. Файлы CNAME (zeno.deforce.site) и .nojekyll уже включены. Сохрани существующие настройки Pages для main / (root) и дождись завершения публикации. Если браузер GitHub скрывает .nojekyll, сохрани уже существующий .nojekyll в репозитории.
6. Открой https://zeno.deforce.site/ и сделай жёсткое обновление (Ctrl+F5). При необходимости закрой старые вкладки и открой сайт заново.
7. «Аккаунт» -> войди Discord -> укажи имя на сайте и ник Minecraft -> «Сохранить профиль». Ник: 3–16 символов A–Z, a–z, цифры или _. Ник не подтверждает владение Minecraft-аккаунтом.
8. «Создать лот» -> выбери предмет -> количество и цену -> «Опубликовать в общей базе».
9. Открой сайт в инкогнито/другом браузере: тот же лот должен быть виден без входа. Проверь профиль продавца. У другого аккаунта не должно быть кнопки удаления твоего лота.
10. Удали тестовый лот своим аккаунтом. В другом браузере нажми «Обновить»: лот должен исчезнуть.

## Безопасность и ограничения

- users/{FirebaseUID}: закрытая привязка пользователя к случайному публичному ID; доступ только своему аккаунту.
- publicProfiles/{publicId}: публичное чтение отдельного профиля; изменение только владельцем. Списковое чтение профилей закрыто.
- lots/{publicId}_{slot}: публичное чтение; запросы списков ограничены limit <= 100; запись нового лота и удаление — только владельцем.
- В публичных документах нет Firebase UID/Discord ID, OAuth-токенов, email или приватного ключа. Лоты используют случайный sellerId. Дата публикации проверяется по времени сервера.
- Правила ограничивают поля, размеры, количества, цены, реальные itemKey из справочника и пути документов. Нельзя добавить fake-admin, verified, photo или изменить чужой остаток.
- Чары и ник — заявления продавца, а не проверка инвентаря в Minecraft. Имя на сайте не уникально и не является знаком доверия.
- Это публичный каталог с прямым чтением Firestore. Ограничение порции не является защитой от массового чтения/спама и не гарантирует, что бесплатной квоты всегда хватит. Следи за Usage в Firebase; при исчерпании квоты запросы могут перестать выполняться. Безлимитной нагрузки эта сборка не обещает.
- Доступ к общим чатам, сделкам и всем другим коллекциям закрыт. Не открывай базу правилом allow read, write: if true.
- Ручная публикация правил обязательна: загрузка файла firestore.rules в GitHub сама по себе НЕ устанавливает правила Firebase.

## Если что-то не работает

permission-denied: проверь, что правила опубликованы именно в проекте zeno-33e37 и базе (default), аккаунт вошёл через работающий Discord Worker, а профиль успешно сохранён.
profile-required/profile-nickname-mismatch: открой «Аккаунт», сохрани профиль с корректным ником и повтори публикацию.
listing-limit: удали ненужный собственный лот (предел 50).
listing-changed: старый лот уже заменён; обнови каталог, не повторяй старое удаление.
unavailable/resource-exhausted: проверь соединение и Usage Firebase; после устранения причины нажми «Обновить».
Данные не заменяются демо-лотами при ошибке базы. Ошибка отображается отдельно; уже загруженные карточки могут быть устаревшими до обновления.
